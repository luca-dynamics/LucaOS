# Onboarding Runtime Spec

## Objective
Initialize identity, model/runtime path, and persistent operational state with minimal user friction.

## Flow
Boot → Runtime subsystem init → Interaction mode (chat/voice) → Identity/preferences → Visual personalization → Model path (Prime/Local/BYOK) → Provisioning checks → Personality/runtime finalization

## Requirements
- Voice and chat onboarding must converge to the same runtime state.
- Model/runtime choices must be transparent and reversible.
- Core/Tactical/Origin mode expectations should be clearly communicated.
