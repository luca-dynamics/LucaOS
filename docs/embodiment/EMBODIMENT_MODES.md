# Embodiment Modes

## Host Modes
1. **Direct Host Mode**: Luca acts directly on the operator's host body.
2. **Sandbox Body Mode**: Luca acts inside isolated VM/container/device environments.
3. **Browser Body Mode**: Luca acts through Ghost Browser runtime.
4. **Remote Delegation Mode**: Luca delegates through LucaLink to other trusted bodies.

## Safety Requirement
Risky experimentation and evolution should default to sandbox body mode, not direct host mode.
