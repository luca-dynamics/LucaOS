# Mission Profile

A Mission Profile turns a broad user objective into durable operating context. It records the mission title and description, goals, constraints, success criteria, related projects, operating mode, priority, status, and lifecycle timestamps.

Operating modes deliberately describe increasing levels of agency:

- `advisory`: Luca recommends but does not execute;
- `collaborative`: Luca and the user iteratively plan work; and
- `supervised_execution`: execution is possible only through future governed runtime adapters.

The profile contract does not bypass existing approval or execution gates. Creation and validation are pure operations with no runtime side effects.
