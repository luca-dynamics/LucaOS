# Personal Intelligence Settings Preview UI Map

PR #207 integrates Personal Intelligence previews into the Settings architecture LucaOS already exposes. It does not add a Personal Intelligence mega-tab, rename a current tab, or replace a current settings component.

## Navigation invariants

The existing navigation IDs and labels remain owned by `settingsExperienceMap` and `settingsNavigationModel`. PR #207 adds no new navigation ID and does not remove or rename `Personality`, `Knowledge Bridge`, `Data & Memory`, `Brain`, `Model Manager`, `MCP Bridge`, or `LucaLink`.

## Preview data policy

The Settings cards use static, non-sensitive examples and safe display metadata derived from the current visible personality selection where available. They do not inspect hidden prompts, raw memories, credentials, private reasoning, files, provider state, model-router state, or LucaLink payloads.
