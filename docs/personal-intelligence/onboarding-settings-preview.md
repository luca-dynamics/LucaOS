# Onboarding and Settings Preview

A future UI may show an Identity Core preview assembled from temporary component state. It may display:

- display and preferred names;
- communication style;
- Luca tone, traits, and boundaries;
- active project references;
- preferred model identifiers as inert preferences;
- device preference metadata; and
- privacy defaults.

The preview may validate missing fields and explain how each field would map. It must not save data, update a runtime profile, select a model/provider, configure a device, change a privacy policy, or imply that clicking a preview control applies anything. Any future apply action requires a separate governed adapter and explicit user confirmation.
