# Computer-Use Spec

## Objective
Provide robust embodied control across desktop/mobile/sandbox environments with verification and recovery.

## Execution Modes
- **Direct Host Mode**: user device automation with strict guard controls.
- **Sandbox Mode**: isolated environment for risky or experimental tasks.

## Requirements
- Mission-engine integrated step execution.
- Cursor/keyboard/window/screenshot primitives.
- Checkpoint + replay trajectory support.
- Verification-first completion criteria.
