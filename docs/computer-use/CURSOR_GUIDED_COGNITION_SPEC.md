# Cursor-Guided Cognition Spec

## Purpose
Use user cursor/selection/attention signals as grounding context for computer-use reasoning.

## Principles
- Treat cursor intent as high-value spatial context.
- Convert UI focus and selection into mission context anchors.
- Reduce global-screen ambiguity with local intent grounding.

## Expected Outcome
More reliable execution on complex visual interfaces and lower hallucinated UI interactions.
