## 2. Intended Perception Table

| Lighting Element | Intended Perceptual Effect |
| :--- | :--- |
| **`keyIntensity`** | Establishes the orb's primary volumetric shape through soft key specular highlights |
| **`keySize`** | Softens key specular halo so light appears generated by a studio softbox |
| **`fillPower`** | Prevents shadow collapse while preserving internal volumetric depth |
| **`rimSoftness`** | Separates the orb from dark backgrounds without creating a metallic chrome outline |
| **`bloomRadius`** | Suggests subtle atmospheric presence around the glass volume rather than a harsh halo |
| **`bloomIntensity`** | Keeps ambient illumination understated, prioritizing glass refraction over self-luminance |

---

## 3. Lighting Architecture

The renderer must implement a 3-point product photography studio lighting model:

- **Primary Key Light**: Positioned upper-left (`UV [0.28, 0.22]`), large softbox source profile.
- **Fill Light**: Positioned lower-right (`UV [0.75, 0.80]`), low-intensity ambient fill to prevent crushed shadows.
- **Rim Light**: Rear upper-left directional Fresnel, wide and soft falloff along key axis.
- **Studio Canvas Environment**: Dark neutral studio background (`#0A0D14`), zero harsh HDR reflections.

---

## 4. Lighting Failure Modes Matrix

| Component | Failure if Too Low | Failure if Too High |
| :--- | :--- | :--- |
| **Key Light** | Flat 2D disc appearance | Harsh overexposed hotspot |
| **Fill Light** | Crushed black shadows | Loss of internal glass depth |
| **Rim Light** | Orb merges into dark canvas | Metallic chrome edge outline |
| **Bloom** | Cold, dead, static appearance | Neon RGB glow or heavy halo |
| **Specular** | Dull plastic material look | Wet chrome or mirror reflection |

---

## 5. Reference Invariants

- **Environmental Highlight**: Specular highlights always read as environmental studio lighting, never painted-on 2D decorations.
- **Embedded Specular**: Specular sits *inside* the volume surface rather than floating above it.
- **Asymmetrical Rim**: Rim light never outlines the full silhouette equally.
- **Soft Shadow**: Contact shadow remains soft and diffused.
- **Subtle Bloom**: Bloom never becomes an artificial halo.
- **Volume Authority**: The eye reads volumetric depth before surface brightness.
