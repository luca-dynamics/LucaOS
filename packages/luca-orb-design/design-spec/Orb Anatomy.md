# Orb Anatomy

The Living Orb is not a flat graphic or shader artifact; it is an **embodied optical liquid object** suspended in physical space.

---

## Structural Layer Hierarchy

```
┌─────────────────────────────────────────────────────────┐
│                    7. Ripple Field                      │
│                  (Environmental Cue)                    │
├─────────────────────────────────────────────────────────┤
│                    6. Ambient Bloom                     │
│                  (Atmospheric Scatter)                  │
├─────────────────────────────────────────────────────────┤
│                 5. Edge Reflectivity                    │
│                (Asymmetrical Fresnel)                   │
├─────────────────────────────────────────────────────────┤
│                 4. Reflective Surface                   │
│               (Painterly Hero Specular)                 │
├─────────────────────────────────────────────────────────┤
│                   3. Liquid Body                        │
│             (Domain-Warped Refractive Glass)            │
├─────────────────────────────────────────────────────────┤
│                 2. Subsurface Glow                      │
│               (Volumetric Light Diffusion)              │
├─────────────────────────────────────────────────────────┤
│                    1. Inner Core                        │
│               (Primary Luminance Center)                │
└─────────────────────────────────────────────────────────┘
```

### 1. Inner Core
- The primary luminance center and soul of the orb.
- Suspended slightly off-center to impart an organic "looking up" quality.

### 2. Subsurface Glow
- Volumetric light scattering inside the liquid mass.
- Light diffuses through the depth of the glass volume rather than being painted on top.

### 3. Liquid Body
- Thick, domain-warped refractive glass body.
- Slightly teardrop-shaped near the bottom under subtle gravitational sag.

### 4. Reflective Surface
- Hero specular highlight rendered as a soft, floating painterly light source.
- Tilted along a studio product lighting axis.

### 5. Edge Reflectivity
- Asymmetrical Fresnel rim lighting.
- Brighter on the upper-left key axis, softer and dimmer along the lower-right shadow edge.

### 6. Ambient Bloom
- Atmospheric light scatter surrounding the orb.
- Subtle and proportional to internal core luminance.

### 7. Ripple Field
- Concentric environmental ripples that pulse gently behind the orb.
- Serves as a subtle cue for state changes, never an overwhelming decoration.
