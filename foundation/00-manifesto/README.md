# 00 · Manifesto

The Manifesto is the _why_ of LucaOS. It is the least likely part of this
repository to change, and the part every other part answers to. Before you read
how LucaOS is built, understand what it is for.

4. **[Presence Is the Product](03-presence-is-the-product.md)** — the reframing

6. **[The North Star](05-north-star.md)** — the sentence we navigate by.

## The Manifesto in one breath

Computers were built around applications. LucaOS is built around **one persistent
AI** — Luca — that is always present, remembers across time and devices, and uses
applications as tools on your behalf. There is exactly one Luca. Every device is a
body it can inhabit. Providers and computer-use are interchangeable infrastructure
underneath. Memory belongs to Luca. **Presence is the product**, and trust is the
condition of everything.
