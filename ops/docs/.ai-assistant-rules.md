# AI Assistant Rules — moved

> **This document has moved.** Engineering standards for AI (and human)
> contributors are now canonical in the Foundation:
> [`foundation/CONTRIBUTING.md`](../../foundation/CONTRIBUTING.md), with agent
> operating instructions in [`foundation/CLAUDE.md`](../../foundation/CLAUDE.md)
> (and the repo-root `CLAUDE.md`).

The good rules this file carried — read before editing, incremental change,
preserve existing exports, type safety, show plans for large changes — are covered
there, provider-neutrally.

**One rule from this file is explicitly retired:** the "Schema & Tool Consistency"
rule that mandated wiring every tool through `geminiService.ts` (a Gemini-specific
service) now *violates*
[Invariant 4 — Provider Abstraction](../../foundation/01-constitution/01-the-eight-invariants.md#invariant-4--provider-abstraction).
Tools flow through the provider-neutral abstraction; no vendor-named service is a
required wiring point. See
[Provider Abstraction](../../foundation/02-specification/04-provider-abstraction.md).
